# Лабораторная работа 6

Учебная работа по автоматизации администрирования Ubuntu с помощью Bash.

`health_check.sh` показывает состояние сервера, ресурсов, служб cron, rsyslog и ufw, обычных пользователей и группы sudo. Пороговые значения CPU, RAM и диска: 85%, 80% и 85%.

`create_users.sh` создаёт пользователей из `employees.csv`, добавляет их в группы отделов и требует сменить временный пароль при первом входе. Повторный запуск пропускает уже существующие учётные записи.

`log_analyze.sh` анализирует `auth_sample.log`: считает успешные и неудачные входы, показывает IP с тремя и более ошибками и попытки sudo без прав.

## Запуск

```bash
chmod +x health_check.sh create_users.sh log_analyze.sh
./health_check.sh
sudo ./create_users.sh employees.csv
./log_analyze.sh auth_sample.log
crontab -l
```

## Пример вывода

```text
cron: active
rsyslog: active
ufw: active
Всего неудачных попыток входа: 11
Успешных входов: 4
Кандидаты на блокировку (неудачных попыток не менее 3):
185.220.101.4 (7)
45.155.205.233 (3)
```

`crontab.txt` содержит расписание запуска `health_check.sh` каждые четыре минуты. Отчёты сохраняются в `~/reports`.
